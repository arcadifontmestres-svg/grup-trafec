# API

Porta única entre el nucli de GRUP TRÀFEC i qualsevol interfície externa.

Criteris:
- permisos validats per Govern;
- cap accés directe a la lògica interna des de miniapps;
- cap duplicació de dades;
- context de centre només quan correspongui;
- respostes limitades al que l'usuari o dispositiu té autoritzat.
