# Dades

Una sola font de dades per a tot GRUP TRÀFEC.

Aquí es definirà l'accés a:
- empreses;
- centres;
- personal;
- permisos;
- CRM;
- reserves i ocupació;
- productes;
- bases;
- plats;
- produccions;
- necessitats;
- compres;
- APPCC;
- RRHH i planning.

No s'acceptaran bases de dades paral·leles per centre o miniapp.
